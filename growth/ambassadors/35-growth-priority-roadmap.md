# Growth Priority Roadmap

The five priorities, in order, with all current and proposed work ranked against them. Anything that does not serve one of these waits or dies. The only metrics that count: Tables Created, Tables Filled, Games Played, Recurring Activity.

## The five priorities (ranked)

1. Las Vegas table formation. The proof. Convert existing relationships into recurring tables. Everything else supports this.
2. Founding Ambassador recruitment. The engine that forms tables without the founder. Las Vegas first, then the launch cities.
3. Teacher outreach. A supply of new players and natural ambassadors. Relationship work now, directory later.
4. Newsletter launch. The weekly habit loop. Las Vegas Mahjong Weekly, manual, this week.
5. Event and open-play inventory. Real, recurring local activity to discover and return for. The content that makes the platform worth checking.

## How to rank any new idea

Score it: does it directly create or fill a table, in a priority city, this quarter. If yes, it competes for time within P1 to P5. If no, it waits. Be willing to say no to good ideas that fail this test.

## Where current and proposed work lands

In (serves P1 to P5, do now):
- Mining the existing Las Vegas email list and CRM into tables (P1). Highest ROI.
- Personal ambassador recruiting from the Oh My Mahjong list, Las Vegas first (P2).
- Teacher outreach as ambassador recruiting; enter teachers in the admin tool (P3).
- Launch Las Vegas Mahjong Weekly by hand (P4).
- Collect open plays and tables into the newsletter and a simple list (P5).
- Use the already-shipped tools weekly: attribution, heat map, relationship pipeline.

Out or deferred (does not move a table this quarter):
- Homepage polish, icons, layout, visual flair (frozen).
- A scrolling venue directory as a build (wrong product; see the Venue vs Activity analysis). Replace with activity-first discovery, manual at first.
- A filter-heavy discovery UI (premature; see the Discovery Layer strategy).
- Public teacher directory, ambassador profiles, city pages (built behind admin; publish only when real).
- National event calendar software, national newsletter, tournaments, leagues, cruises, retreats as builds.
- The paid mahjong-friendly business program, SMS, PWA prompts, advertiser funnel.
- Producing more strategy documents beyond this set. The library is complete; execute.

## The honest tension

The five priorities are about supply and relationships, not product. We have spent recent cycles on product and strategy. The roadmap going forward is mostly non-product: calls, recruiting, a weekly email, and listing real activity. Protect that. The temptation will be to build something; resist it unless it passes the test above.

## Quarter shape

- This month: P1 and P4 hard (Las Vegas tables plus the weekly newsletter), P2 in parallel (ambassadors), P3 and P5 as they support those.
- Next two months: extend the same motion to Phoenix and Boca; deepen Las Vegas toward self-sustaining; let open-play inventory (P5) grow as cities get dense.

The roadmap is short on purpose. A short roadmap executed beats a long one admired.
