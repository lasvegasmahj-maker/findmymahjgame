# Homepage Freeze Recommendation

Recommendation: freeze the homepage. It is good enough and it is not the bottleneck. Further work on icons, button styling, layout, or visual polish should stop unless a specific change can be shown to move tables created, filled, played, or recurring.

## Why freeze now

- The homepage already does its one job: a first-time visitor sees three clear actions (I Want to Play, Start a Table, I Need Help) immediately, in large high-contrast text, on mobile, with nothing competing for attention. That is the whole requirement.
- The recent changes (text-only buttons, removing the install popup) were the right last touches: maximum clarity, no interruption, no decoration. There is little left to gain.
- The bottleneck is not the homepage. It is supply: real tables, real players, real hosts in real cities. No homepage tweak creates a single table. Time spent polishing the front door is time not spent filling the rooms.
- Design iteration has diminishing returns and a real cost: every cycle on visual polish is a cycle not spent on Las Vegas table formation, ambassador recruiting, teacher outreach, or the newsletter.

## The freeze rule

Do not change the homepage unless the change clearly improves one of: Tables Created, Tables Filled, Games Played, or Recurring Activity. Cosmetic preference is not a reason. The test before any homepage edit: "What is the evidence this seats more players at more recurring tables." If there is no such evidence, it waits.

Allowed exceptions (still must pass the test):
- A measured conversion problem (for example, people reaching the homepage and not tapping any action). Fix the specific blocker, not the aesthetics.
- A correctness or accessibility fix (a broken link, an unreadable element on a real device).
- Surfacing real activity that drives action (for example, live "tables forming now" already does this). Adding real, actionable local content can earn its place; adding decoration cannot.

## What this frees us to do

The homepage freeze is not about the homepage. It is about reallocating attention to the five current priorities (Las Vegas table formation, ambassador recruitment, teacher outreach, newsletter launch, event and open-play inventory). Those create tables. The homepage does not need us anymore; the cities do.

## Revisit criteria

Reopen homepage work only when there is data showing a homepage change would lift a core metric, or when new, real local content (open plays, tables, a local newsletter signup) is ready to surface and would drive action. Until then, the homepage is done.
