## Workstream 4: Table-formation friction audit (target: under 2 minutes)
Measured against the real built flow.

**Join path (player):** Home → I Want to Play → type town → see games → Claim (first name + phone or email) → "You're in!"
- Realistic time when a game exists: ~50-70s. **Under 2 min: yes.**
- Friction ranked: (1) **typing the town** is the slowest step for a 75-year-old → add **"Use my location"** (one tap). (2) Two contact fields can read as "both required" → the helper says otherwise; watch in testing. (3) If no game exists, it becomes a capture (good, no dead end) but that is not a formed table, the fix is supply (ambassadors) not UX.

**Start path (host):** Home → Start a Table → day, time, area, who → first name + contact → "Table is up!" → share.
- Realistic time: ~60-90s. **Under 2 min: yes**, but it is the densest screen.
- Friction ranked: (1) **single long screen** (7 day-chips + time + area + skill + name + contact) → optional split into 2-3 one-question steps if testing shows fatigue. (2) area typing → same "use my location"/autocomplete fix.

**Top 3 friction fixes (impact order):** 1) "Use my location" + town autocomplete (kills the slowest step on both paths). 2) SMS confirmation/alerts (this audience acts on texts). 3) Optionally step-split Start a Table.

## Workstream 2: PWA implementation plan
Goal: feels like an app, no download, no App Store.
- **Add to Home Screen + icon + splash:** add `app/manifest.ts` (name, short_name "Mahj", theme/background color navy, display "standalone", start_url "/"), and icon set (192/512 + maskable) and apple-touch-icon. Splash is generated by the browser from the manifest + icons. **Effort: ~0.5 day.**
- **Install prompt:** a gentle, dismissible "Add Mahj to your phone" big card on the home screen (capture `beforeinstallprompt` on Android; show iOS Safari "tap Share → Add to Home Screen" instructions). **Effort: ~0.5 day.**
- **Offline shell:** a minimal service worker caching the app shell + a friendly offline page (don't over-cache dynamic data). **Effort: ~0.5-1 day.**
- **Push notifications (roadmap, not now):** Web Push for "your table filled," "1 seat left," "your game is in 2 days." iOS supports web push only for installed PWAs (16.4+), so it depends on Add-to-Home adoption. **Effort: ~2-3 days; do after install adoption is real.** SMS beats push for this audience in the meantime.
- **Timeline:** the install/manifest/icons/offline shell is a **~2-day** task; schedule it right after the wedge is in production. Push is a later phase.
