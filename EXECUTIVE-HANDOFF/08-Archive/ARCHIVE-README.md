# Archive

Historical material, kept so nothing is lost. This is not the current plan. Where anything here disagrees with the documents in folders 01 through 07, those current documents win.

## What is here

- architecture.md, schema.md, security.md. Technical references for the website, the data, and security. Useful only for a developer or technical helper.
- historical-growth-strategy/. Earlier strategy exploration from the first part of the sprint.

## About the historical growth strategy

These documents were an early, wide exploration before we focused on the ambassador and city-launch approach. They are useful for context and for some still-relevant detail (for example, SEO and competitive notes), but several recommendations have been superseded.

- The 8-part growth sprint (01 through 08) explored competitive intelligence, SEO, product growth, viral loops, a UX audit, supply acquisition, data strategy, and a roadmap. Still useful for SEO and competitive context.
- The 60-day folder was an earlier execution plan. Superseded by the current 30-day blitz and the city-launch plans.
- The product-model folder analyzed whether to be a marketplace, an event product, a matching product, or a community. That question is decided: a directory plus a table-formation tool, grown through ambassadors. Treat it as closed.
- las-vegas-table-formation-plan.md is an earlier Las Vegas plan, superseded by the current Las Vegas launch plan in folder 05.
- EXECUTION-STACK.md, hyperspeed.md, mahj-concierge.md, war-room-blitz.md, and senior-mobile-design.md were brainstorms and idea documents. Useful for inspiration, superseded by the focused City Launch Mode.

If you only have time for the current plan, you can skip this folder entirely. It is here for completeness and history.
